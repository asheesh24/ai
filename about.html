About the Project

AI Fault Diagnosis Using Forward and Backward Chaining

Project Overview

This project demonstrates how Artificial Intelligence can be used to diagnose faults using knowledge-based reasoning. The system uses facts, rules and an inference engine to identify possible causes of a problem.

🎯

Objective

To develop an intelligent system capable of identifying possible faults from observed symptoms.

🧠

Technology

HTML, CSS, JavaScript and rule-based artificial intelligence concepts are used.

⚙️

Reasoning

Forward chaining and backward chaining are used as inference techniques.

Project Objectives

  • Understand knowledge-based AI systems.
  • Implement rule-based reasoning.
  • Demonstrate forward chaining.
  • Demonstrate backward chaining.
  • Build an interactive fault diagnosis system.
  • Provide understandable diagnostic results.
